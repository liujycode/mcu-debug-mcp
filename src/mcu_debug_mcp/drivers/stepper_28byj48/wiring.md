# 28BYJ-48 步进电机接线与坑（按翻车率排序）

## 标准接线（28BYJ-48 + ULN2003 板）

| ULN2003 板 | 接哪里 |
|-----------|--------|
| IN1-IN4 | MCU 4 路推挽 GPIO |
| GND | 与 MCU **共地** |
| VCC/5V | 独立 5V（电机电流大，别蹭 MCU 的） |
| 白色 5 针座 | 28BYJ-48 插头直插（防呆，插反=抖不转） |

## 坑清单

1. **插头能反插 → 相序错 → 只抖不转**。28BYJ-48 的 5 针插头没有真防呆，
   反插就四相乱序。现象：电机高频抖动/嗡嗡但不转。先把插头翻个面试试。

2. **2048/4096 是近似值，精确是 2038/4076**。标称减速比 64:1，
   精确值 63.68395:1（四级齿轮 32/9×22/11×26/9×31/10）。
   按 2048 走一圈实际 360.18°，单圈看不出来；云台转 50 圈差出 9°。
   要精确角度用本驱动默认的精确值，误差要吸收就机械标定。

3. **转速上不去（>15RPM 就失步）**。28BYJ-48 齿轮减速+小转矩，跑 15RPM
   是极限，硬跑会"丢步"——指令走了步数，轴没跟上。要快换
   NEMA17 + A4988，别为难它。

4. **HAL_Delay 的 1ms 粒度**。15RPM 半步延时约 1ms/步，HAL_Delay(1)+循环
   开销会拖慢到 10RPM 以下；要求准就上 DWT/TIM us 级延时（同 DHT11）。

5. **断电丢位置**。开环步进没有位置反馈，上电时电机在哪没人知道。
   需要绝对位置就加限位开关做"回零"，答辩时这是常见追问。

## 答辩/调试加分点

- 说出"减速比 63.684 不是 64、半步 4076 步/圈、8 拍相序"三个数，就赢了 90% 的同学。
- 相序：半步 8 拍一相→两相交替，全步 4 拍永远两相励磁（转矩大、发热也大）。
- 丢步 vs 堵转分清：丢步=转速超了没跟上（静音滑过），堵转=机械卡死（嗡嗡发热）。
