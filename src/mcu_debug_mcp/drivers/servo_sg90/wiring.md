# SG90 舵机接线与坑（按翻车率排序）

## 标准接线

| 舵机线 | 接哪里 |
|--------|--------|
| 橙（信号） | MCU 任意定时器 PWM 输出脚（50Hz） |
| 红（VCC） | **独立 5V 电源**（不要接 MCU 的 5V！） |
| 棕（GND） | 与 MCU **共地** |

## 坑清单

1. **MCU 5V 直接供电 = 头号坑**。SG90 堵转电流 700mA+，而多数开发板 USB 5V 只有 500mA——
   舵机一动电压瞬间塌陷，MCU 复位、串口乱码、程序莫名重启。现象高度像"固件 bug"，
   实际是供电。独立 5V（或大容量电源）+ 共地，一根线的事。

2. **PWM 周期不是 20ms → 舵机嗡嗡叫/抖动/不转**。PSC/ARR 配错了。
   自查公式：周期 = (ARR+1) × (PSC+1) / 定时器时钟。
   例：72MHz / (71+1) = 1MHz tick；(19999+1) tick = 20ms ✓
   本驱动的 servo_pulse_to_ccr 会先验周期是否在 19-21ms，配错直接报 -1。

3. **0°/180° 到不了**。SG90 个体差异大，500/2500us 是理论值，不少个体
   到头会机械限位"咔咔"响。项目里实际用 10-170°；要用全行程就实测后
   收紧 SERVO_PULSE_MIN_US/MAX_US。

4. **多个舵机一起动 → 复位**。每个舵机堵转 700mA+，两个就 1.5A。
   独立电源按 1A/舵机 留余量，电源入口加大电容（470uF+）。

5. **MG995/MG996R 大舵机不是 500-2500**。金属齿大舵机脉宽常是 1000-2000us，
   照抄 SG90 参数会转不到位。换舵机先查手册改 MIN/MAX。

## 答辩/调试加分点

- 说出"周期 20ms、脉宽 0.5-2.5ms 线性对应 0-180°、中位 1500us"这三个数，就是懂了舵机。
- 换算链：角度 → 脉宽 → CCR，每步都可以在 PC 上先算好再上板（本驱动的纯函数就为此设计）。
