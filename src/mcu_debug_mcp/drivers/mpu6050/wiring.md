# MPU6050 接线与避坑指南（GY-521 模块）

## 接线（GY-521 模块 8 脚，常用 5 根）

```
GY-521           MCU (3.3V/5V 均可，模块板载稳压)
┌────────┐
│ VCC ──────────── 3.3V
│ GND ──────────── GND
│ SCL ──────────── I2C SCL（例：PB8）
│ SDA ──────────── I2C SDA（例：PB9）
│ AD0 ──────────── GND（地址 0x68；接 VCC 则为 0x69）
│ (XCL/XDA/INT 悬空)
└────────┘
```

## 头号坑清单

| 坑 | 症状 | 解法 |
|---|---|---|
| 上电处于睡眠模式 | 三轴全 0（命中 SENSOR_ZERO） | PWR_MGMT_1 写 0x00 解除睡眠——**不做这步永远读不到数**，本驱动 init 已处理 |
| AD0 悬空 | 偶发读不到/地址漂移 | AD0 必须明确接 GND 或 VCC，悬空时地址不确定 |
| 8 位地址当 7 位用 | I2C NACK | 手册写 0xD0/0xD1 是含读写位的 8 位形式，7 位地址是 0x68。HAL 用 `(addr7<<1)` |
| I2C 时钟超 400kHz | NACK/数据错乱 | MPU6050 上限 400kHz，初学先 100kHz 跑通再提速 |
| 静止校准缺失 | 姿态解算漂移 | 上电静置 2s 采均值做陀螺零偏校准；加速度合成应 ≈1g（本驱动 static_check 可验） |

## 输出解读（配合本 MCP 的 analyzer）

- 全 **0** 且 WHO_AM_I 也读不到 → 命中 `SENSOR_ZERO`：接线/睡眠模式
- **I2C NACK** → 命中 `I2C_NACK`：地址（AD0）/上拉/时钟过高
- 数值乱跳 → 供电纹波或模块没固定；先 static_check 自检
- 温度显示 **36.53** 左右 → 传感器刚解除睡眠还没稳定，正常现象（raw=0）

## 答辩加分点

1. **DLPF 低通滤波**：CONFIG 寄存器 DLPF_CFG 的截止频率取舍（带宽 vs 延迟），控制类毕设必讲
2. **互补滤波/Kalman**：MPU6050 输出加速度+角速度，融合出姿态角——毕设的"算法含金量"就在这里
3. **量程档位**：±2g 精度高但易饱和、±16g 反之，按应用场景选型（讲工程权衡）
4. **零偏校准方法**：说明为什么要静置采均值（MEMS 传感器固有零偏误差）
