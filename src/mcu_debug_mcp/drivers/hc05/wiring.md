# HC-05 蓝牙模块接线与坑（按翻车率排序）

## 标准接线

| HC-05 | 接哪里 |
|-------|--------|
| TXD | MCU RXD（**接 TX 是最经典事故**） |
| RXD | MCU TXD |
| VCC | 5V（板载稳压降到 3.3V，通信脚是 3.3V TTL） |
| GND | 共地 |
| EN/KEY | 进 AT 模式才用：**拉高后再上电** |

## 坑清单

1. **AT 发出去没反应 → 十有八九是波特率不对**。HC-05 有两个波特率：
   - 透传（正常工作）模式：**9600**
   - AT 模式（EN 拉高上电后）：**38400**
   用 9600 发 AT 没反应？先确认进的是 AT 模式，再用 38400 试。

2. **透传模式下 AT 就是不理你**。透传模式里它只是一根"蓝牙串口线"，
   你发的 AT 会被原样发给对端。现象像坏了，实际是模式不对。
   模块 LED 慢闪（2 秒周期）= AT 模式；快闪/双闪 = 透传模式。

3. **没看到 EN 脚的板子**：按住模块上小按键再上电（或上电时短接 EN 焊盘）进 AT 模式。
   ZS-040 版本带 EN 按键脚；美版/兼容板按键位置各异，找不到就照丝印找 KEY。

4. **改完波特率自己断线**。`AT+UART=115200,0,0` 执行完，串口助手还连着 38400
   当然没响应——先把助手切到新波特率再说话。别以为改坏了。

5. **HC-05 和 HC-06 是两套命令集**（外形几乎一样，大坑）：
   | 操作 | HC-05 | HC-06 |
   |------|-------|-------|
   | 设波特率 | AT+UART=115200,0,0 | AT+BAUD8 |
   | 查询要问号 | AT+NAME? | AT+NAME（不带?） |
   | 行结尾 | \r\n | 无行尾 |
   拿错手册照着敲，怎么敲都 ERROR。先 AT+VERSION? 看回什么再对号入座。

6. **ERROR:(1) 含义各固件不统一**。别硬背：格式错就检查问号/等号/逗号；
   范围错就查参数列表。本驱动只提取细分码，判断靠 `AT+UART?` 这类查询命令验证。

## 常用命令速查（AT 模式 38400）

```
AT                      → OK（握手）
AT+NAME?               → +NAME:HC-05（改：AT+NAME=MyBT）
AT+PSWD?               → +PSWD:1234（改：AT+PSWD="0000"）
AT+UART=9600,0,0       → OK（透传波特率）
AT+ROLE=0              → 从模式（1=主）
AT+RESET               → OK（生效需复位）
```

## 答辩/调试加分点

- "两个波特率、两种模式"这张表说出来，面试官就知道你真调过。
- TX/RX 交叉 + 3.3V TTL 电平 + EN 进 AT，是蓝牙模块调试三板斧。
