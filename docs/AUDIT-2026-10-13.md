## 一、P0 阻断项（上线前必须清）

### P0-1 发布产物是空壳 —— 已完整复现，因果链闭合 [实测]

不是"可能有问题"，是我构建出来看到的：

| 实验 | 命令 | 结果 |
|---|---|---|
| ① 直接从源码建 wheel | `python -m build --wheel --no-isolation` | 90 条目，**knowledge+drivers 60 个文件** ✅ |
| ② 标准发布流程 | `python -m build --no-isolation` | sdist 32 条目 **0 个数据文件**；wheel **11 条目 0 个数据文件** ❌ |
| ③ 装进干净 venv 实跑 | 装②的 wheel → 调工具 | `error_code_lookup` → "错误码知识库为空"；`driver_list` → "驱动库目录不存在" ❌ |

**因果链**：`MANIFEST.in` 缺失 → sdist 不含数据目录 → 而 `python -m build` 的 **wheel 是从 sdist 解包后构建的**（实验①vs②的差别就在这一步）→ 空壳传染给 wheel → 用户装到空壳。

`setup.py:2-16` 的 docstring 正是把"装出来只有 3 个 .py、知识库全丢"当作**已修复的历史 P0** 来写的——**它复发在另一条路径上（sdist）**，而现有钩子只覆盖了 wheel 直构路径。

**修法**：加 `MANIFEST.in` 纳入 `knowledge/` `drivers/` `tools/`；`setup.py:41-42` 的 `continue` 改成数据目录缺失即 `raise`（消除静默降级）；CI 增加"从 sdist 构建 + 安装 + 探针"这一步。

### P0-2 打包冒烟测试是假绿灯 —— 这条最危险 [实测]

`tests/test_package_smoke.py` **9 passed**，它里面有 `assertGreaterEqual(n_know, 10, "knowledge/ 没进包")` 这种看着很硬的断言。但它用 `pip install . --no-build-isolation --target` —— **直接从源码树构建 wheel**，正好绕开 sdist 路径，于是永远测不到真实发布产物。

讽刺的是该文件 242-245 行有一段自我批评："这里曾经是 skipTest —— 于是'打包坏了'被伪装成'环境不支持'，测试永远绿，而缺陷照样发出去"。**同样的病换了个位置复发，这次在测试的安装源选择上。**

**修法**：冒烟测试参数化安装源，wheel 与 sdist **两条都跑**；CI 增加 `python -m build` → 装 `dist/*.tar.gz` → 跑同一套探针断言。

### P0-3 `flash_verify` 回读失败仍打印"✓ 完全一致" [实测读码]

`core.py:2846-2879`：`seg_bad` 只在**逐字节比对**分支里累加（2871 行），而"回读失败/临时文件读不到/回读长度不符"三条失败分支（2854/2861/2865）只加 `bad_total` 并 `break`。到 2878 行 `if seg_bad == 0:` 依然成立 → 打印 **"✓ 完全一致"**。

也就是说：**探针掉线、SWD 断开、读保护打开时，校验工具会给用户"固件已正确烧入"的假结论。** 一个校验类工具给假通过，性质比普通 bug 严重。

**修法**：失败分支加 `seg_ok = False`，结论行区分"一致 / 未能校验"。

### P0-4 知识库事实错误，且盖了 3GPP 出处章 [实测]

`knowledge/error_codes/cme.json` 把 **CME ERROR 12 释义为"SIM 的 PIN 码错误"**。3GPP TS 27.007 §9.2.1 原文：**12 = SIM PUK required**（PIN 错误是 11；incorrect password 是 16）。SimCom/Telit 厂商手册与标准三方一致。

危害路径：用户 `AT+CPIN?` 卡被锁 → 模块回 `+CME ERROR: 12` → 工具输出"注意剩余重试次数" → 用户继续试 PIN → **可能把 SIM 彻底锁死**。正确方向是用 PUK 解锁。而同表恰恰**没收录 16（incorrect password，正是本条正解）**。

**修法**：12 改为 "SIM PUK required（需 PUK 解锁）"；补录 14 SIM busy / 15 SIM wrong / 16 incorrect password。
