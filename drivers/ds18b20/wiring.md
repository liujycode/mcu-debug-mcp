# DS18B20 接线与避坑指南

## 接线（裸传感器 TO-92 三脚）

```
DS18B20          MCU (3.3V)
┌────────┐
│  1 VCC ────────── 3.3V
│  2 DQ  ───[4.7kΩ 上拉到 3.3V]─── GPIO（开漏/输入上拉）
│  3 GND ────────── GND
└────────┘
```

- **DQ 必须上拉 4.7kΩ**（到 VCC）。没上拉 = 读到全 0xFF 或无应答。
- 多点组网（同一总线挂多只）：每只都要独立验证时序，多器件需 ROM 命令（本驱动只做单器件 Skip ROM 版）。

## 头号坑清单（按翻车频率排序）

| 坑 | 症状 | 解法 |
|---|---|---|
| 等待不足 750ms | **恒 85.0°C**（复位值） | 发 0x44 后必须等满 750ms（12 位）。等 100ms 读出来的一定是 85 |
| 用 HAL_Delay 做时序 | 读超时/全 FF | 单总线要微秒级时序，HAL_Delay 毫秒粒度不够，用 DWT CYCCNT |
| 寄生供电 + 转换 | 85.0 或 CRC 错 | 转换瞬间电流 1.5mA，寄生模式撑不住 → VCC 直接供电；非要寄生就得强上拉（MOS 管） |
| 读时序被中断打断 | CRC 校验失败 | 单总线时隙 60-120us，任何中断 >10us 都可能毁掉一个 bit。读期间临时关中断 |
| 上拉接了但线太长 | 偶发 CRC 错 | 线长 >1m 时降上拉到 2.2k 或加驱动；杜邦线 >30cm 就容易出问题 |

## 输出解读（配合本 MCP 的 analyzer）

- 恒 **85.0** → 命中 `DS18B20_85` 规则：转换命令没生效（上表第 1、3 条）
- 恒 **-127** → 多数库的"无应答"错误码：命中 `NEG_INVALID`，查上拉/接线
- 全 **0xFF** → 命中 `SENSOR_FF`：DQ 悬空/上拉缺失
- 偶发 CRC 错 → 上表第 4、5 条（中断/线长）

## 答辩加分点

1. **CRC 校验的意义**：单总线无 ACK 机制，靠 CRC8 保证数据完整性——可以讲为什么嵌入式协议都要带校验
2. **寄生供电原理**：DQ 线同时供电+通信的电路设计取舍（毕设 PPT 有东西可写）
3. **分辨率/转换时间权衡**：9 位(93.75ms)~12 位(750ms)，按采样率需求配置
4. **温度补偿联动**：DS18B20 + HC-SR04 做声速温度补偿 = 一个漂亮的创新点组合
